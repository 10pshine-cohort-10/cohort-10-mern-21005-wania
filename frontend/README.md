# Notes App

A web-based application for creating and managing personal notes.

## Implemented Features

- User login page
- User signup page
- Password visibility toggle
- Login API integration
- Redirect to dashboard after successful login
- Temporary dashboard page for testing login redirection

## Technologies Used

- React.js
- TypeScript
- React Router
- CSS
- Lucide React

## Setup

1. Open the `frontend` folder.
2. Install the required dependencies:

   `npm install`

3. Start the development server:

   `npm run dev`
