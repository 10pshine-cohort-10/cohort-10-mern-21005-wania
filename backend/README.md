# Backend Setup

## Database Setup

1. Create a MySQL database named `notes_app`.
2. Open the `database/schema.sql` file.
3. Run the SQL commands to create the login attempt tables.

## Run Backend

1. Open the backend folder in the terminal.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file and add your database and JWT configuration.
4. Start the backend:

   ```bash
   npm run dev
   ```

The backend runs at `http://localhost:5000`.
